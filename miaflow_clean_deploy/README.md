# MiaFlow Clean Deploy

This is the clean deploy-ready version of MiaFlow.

## Important

Upload the CONTENTS of this folder directly to GitHub root.

Your GitHub repo should look like:

app/
lib/
package.json
next.config.js
tsconfig.json
README.md

Then in Vercel:

- Framework: Next.js
- Root Directory: blank or ./
- Output Directory: blank

## Run locally

npm install
npm run dev
